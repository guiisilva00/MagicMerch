O QUE É O PROJETO?
A 
MagicMerch
 vende produtos artesanais (
hand-made
) focados em cultura pop: cards, camisetas, moletons, acessórios, canecas, perfumes, banners, posters e outros itens colecionáveis.
Atualmente tudo é feito 
100% manual
 — DMs, WhatsApp, planilhas Excel, bloco de notas. Caótico demais. O objetivo é criar um site onde:
Clientes navegam, filtram, compram sozinhos
Estoque é atualizado automaticamente
Frete é calculado de forma inteligente
Programa de fidelidade roda sozinho
PROBLEMAS QUE PRECISAMOS RESOLVER
Problema
Impacto
Como Vamos Resolver
Sem catálogo online
Perda de vendas, clientes indo pra concorrência
Criar site com todos os produtos listados
Estoque desatualizado
Overbooking, sobrevenda, clientes putos
Sistema automatizado que decrementa ao comprar
Frete manual pra cada cliente
Demora, erros, clientes desistem
Calcular automático por CEP/estado
Programa de fidelidade bagunçado
Clientes não sabem quantos pontos têm
Contador visual que atualiza automaticamente
Sem rastreamento de pedido
Cliente fica perdido, fica achando que foi enganado
Painel com status atualizado (em produção, enviado, etc)
Nenhum histórico de compras
Impossível gerenciar, analisar dados
Dashboard administrativo com tudo

 REGRAS DE NEGÓCIO
Código
Nome
O Que É
RN01
Atualização Automática de Estoque
Quando alguém compra, o estoque decresce automaticamente. Se acabar, muda pra "Esgotado"
RN02
Programa de Fidelidade
A cada 10 produtos comprados (acumulado), ganha 1 brinde/produto extra
RN03
Frete Regionalizado SP
Pedidos de SP têm frete reduzido. Resto do Brasil paga mais
RN04
Modalidades de Entrega
Opções: Retirada na loja (grátis) ou Entrega no endereço (com frete)
RN05
Acesso Admin Único
Só uma conta admin (login + senha exclusiva)
RN06
Identidade Visual
Paleta obrigatória: Roxo, Rosa e Branco — estilo clean tipo WeVerse
