# MagicMerch

Desenvolvimento de uma plataforma de e-commerce moderna e personalizada para a MagicMerch, focada em otimizar a experiência de compra do cliente e simplificar a gestão operacional de vendas. O sistema integra catálogo de produtos, regras de negócio exclusivas, navegação intuitiva e controle administrativo centralizado.
